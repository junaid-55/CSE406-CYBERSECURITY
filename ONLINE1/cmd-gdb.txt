3  -->  fgets(str, size, stream)

  - reads at most (size - 1) chars, always reserves 1 byte for '\0'
  - stops early on: '\n' (kept in str), or EOF
  - returns NULL on EOF/error with nothing read -> str unchanged, must guard with if()
  - stream position is persistent between calls -> repeated calls
    continue from where the last one left off, NOT from start of file

  strip trailing newline:
    str[strcspn(str, "\n")] = '\0';

  gotcha:
    fgets(str, 4, f)  reads only 3 chars, not 4  (off-by-one to remember)

  reset stream to start:
    rewind(stream);        // or fseek(stream, 0, SEEK_SET);
